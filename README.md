Overview:

This repository contains the analysis for two separate tasks: one involving the Gapminder dataset to analyze global life expectancy and GDP trends, and another evaluating the effectiveness of a hospital discharge program for faster patient recovery. Both tasks involve data cleaning, exploration, visualization, and statistical modeling.

Files:

gapminder_analysis.R: Contains the analysis for Task 1, including data processing, visualizations, and conclusions based on life expectancy and GDP data.

hospital_program_analysis.R: Contains the analysis for Task 2, including data cleaning, exploratory analysis, and statistical models for evaluating the discharge program's effectiveness.

R: Data analysis and visualization using R packages such as ggplot2, dplyr, and gapminder
